# Life-Point 完全重构计划(v0.6.0「纪念册」)

## 一、现状诊断结论

**功能缺口**(PRD P0 有 4 项完全未做):列表视图、人生阶段模板一键铺底、500+ 事件性能兜底、键盘导航;P1(配图/地点/参与人/心情)全部未动。
**UX 问题**:冷启动无引导(建档后空白时间线靠手打);录入是重表单长弹窗(类型+双精度+5 档重要度+8 分类一步全上);首页仪表盘价值低;移动端导航是顶部横滑小标签;搜索无快捷键。
**UI 问题**:emoji 当图标、白卡灰底无个性、层级弱、时间线卡片密度低且视觉单调。
**架构问题**:全局弹窗与页面弹窗双轨并存;业务逻辑散在视图层;`constants.ts` 大杂烩;无虚拟滚动。

## 二、已确定的方向(按推荐项)

| 决策 | 选择 |
|---|---|
| 视觉风格 | **温暖纪念册风**:纸质感底色 + 衬线大标题 + 编辑排版 + 暖棕强调,像一本人生纪念册 |
| 功能范围 | **P0 补全 + 内容丰富包**(配图/地点/参与人/心情);回顾包(那年今日)纳入统计页 |
| 数据 | **无损迁移**:Dexie schema v3→v4 自动升级,导出格式 2.1 向后兼容 1.0/2.0 |
| 技术栈 | 保留 Vue 3.5 + Vite + Pinia + Dexie;**Tailwind 升 v4**(CSS-first 设计令牌);**lucide-vue-next 替换全部 emoji 图标**;思源宋体(Noto Serif SC)标题 + 系统无衬线正文 |

## 三、新信息架构

- **时间线 = 首页**。删除现有低价值仪表盘首页,`/` 直接是时间线(未建档则显示欢迎建档页 → 模板引导)。
- 导航:桌面顶栏(Logo + 时间线/回顾/统计/档案/设置 + 搜索 + ⌘K);**移动端底部固定 tab 栏**(替代现在的横滑标签)。
- 路由精简为:`/`(时间线)、`/list`(列表)、`/stats`(统计+回顾)、`/profile`、`/settings`。

## 四、新视觉体系(CSS-first 设计令牌)

- 纸面 `#FAF7F2` / 墨色 `#2A2622` / 暖棕强调 `#B8834D`;暗色:深暖炭 `#191613` 底。
- 8 分类色整体降饱和重调,与纸面和谐;区间色带沿用点=实心节点/区间=色带的强区分语言。
- 字体:标题 Noto Serif SC(衬线,大号年份水印、卡片标题),正文系统无衬线。
- 8px 网格、统一圆角(卡片 16px)、暖阴影、动效时长表(150/250/400ms + reduced-motion 降级)。
- 组件库 `components/ui/`:Button/Input/Modal/BottomSheet/Toast/Chip/SegmentedControl/EmptyState/Skeleton/StarRating,全部新写。

## 五、时间线重构(核心)

1. **虚拟滚动**:只渲染可视区 ± 缓冲年份组,500+ 事件不掉帧(产品红线);年份导航尺、吸顶年份保留。
2. **视觉分层**:里程碑(≥5)大卡衬线标题 + 发光环节点;大事(4)标准卡;小事(≤3)紧凑单行条目;年龄标注(「23 岁 · 2016」)。
3. **密度切换**:「纪念册 / 只看大事」两档,替代现在的筛选开关。
4. **键盘导航**:`/` 聚焦搜索、`N` 新建、`↑↓` 事件间移动、`Enter` 展开、`Esc` 关闭。
5. 导出图片改为「当前视图导出」(虚拟滚动下 DOM 不再含全部内容)。

## 六、录入与编辑重构

- **QuickCapture 快速记录**:FAB / 顶栏 + / ⌘K 打开,首屏只需 标题 + 日期(默认今天),分类/重要度/描述收进「详细信息」折叠区;支持连续添加;移动端用底部 BottomSheet。
- **EventSheet 重构**:点/区间分段器置顶,日期与精度行内切换,跨度实时预览,重要度星级,校验即时反馈。
- 删除确认 + 30 秒撤销迁移到统一 Toast 系统。
- **列表视图 `/list`**:表格/行式布局,筛选复用、行内编辑、批量选择删除。
- **人生模板**:建档完成后推荐页(学制/职业等模板)一键生成阶段草稿(`isDraft` 虚线卡片),逐条确认编辑,解决冷启动。

## 七、内容丰富包(P1 落地)

- 事件配图:多图,存 IndexedDB Blob(新表 `images`),卡片封面 + 详情画廊。
- 地点、参与人、心情标签字段;详情弹层(时间线卡片点击展开)完整呈现。

## 八、数据模型与迁移

## 十、开发阶段(每阶段一个 PR,feat/v0.6.x-*,CI 不变)

1. **P1 基建**:Tailwind v4 + 设计令牌 + ui 组件库 + 图标/字体引入(旧页面兼容运行)
2. **P2 应用壳**:导航重构(底部 tab/顶栏)、路由精简(时间线成为首页)、暗色重做
3. **P3 时间线**:虚拟滚动 + 新视觉 + 年龄标注 + 密度切换 + 键盘导航
4. **P4 录入**:QuickCapture + EventSheet + BottomSheet + Toast 统一 + 连续添加
5. **P5 整理**:列表视图 + 人生模板 + 冷启动引导
6. **P6 内容**:images 表 + 配图/地点/参与人/心情 + 事件详情弹层
7. **P7 统计回顾**:统计页新视觉 + 人生比例图 + 那年今日 + 导出海报
8. **P8 收尾**:500 条压测验收、测试迁移(现有 24 用例重写适配)+ 新增、README/PRD 文档对齐、版本号 0.6.0

## 十一、验收标准

- 冷启动 → 模板铺底 → 10 分钟建档 20 条
- 500 条事件滚动 60fps,动画降级策略生效
- 全键盘完成浏览/搜索/录入;`prefers-reduced-motion` 全局尊重
- 375px 移动端完整可用;暗色模式全页面覆盖
- 旧 IndexedDB 数据升级无感,JSON 导出可回灌旧版不报错

## 十二、风险与对策

- Tailwind v4 与现有 `@tailwindcss/forms` 兼容:用 `@plugin` 方式接入,失败则退回 v3(全部样式本来就要重写,迁移成本可控)
- html-to-image 在虚拟滚动下导出不全:改为「当前视图」导出 + 独立海报模式
- Dexie 迁移:用 fake-indexeddb 写 v3→v4 迁移单测
- 阶段多、PR 大:P1-P2 先合并保底可用,后续每阶段独立可回滚

执行时先建 `feat/v0.6.0-album-redesign` 分支,按阶段提交。
