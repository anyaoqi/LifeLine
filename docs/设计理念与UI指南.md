# Life-Point 设计理念与UI指南

## 🎨 核心设计理念

> 需求依据见 [产品需求规格](./产品需求规格.md)。本文只讲「长什么样、怎么动」。

### **应用目的**
帮助用户清晰、完整地看到自己从出生到现在的所有人生事件记录 —— 既包括上学、工作、结婚、生子、亲人离世这类**大事**，也包括过生日、去新疆旅游、第一次出国这类**小事**，让每个人生节点都清晰可见，支持回顾、反思和记录自己的人生轨迹。

### **设计三大支柱**
1. **清晰的时间线** - 时间轴是主视角，一眼看透人生全景；大事是主干，小事是枝叶，永远不能让枝叶盖住主干
2. **丝滑的交互体验** - 流畅的动画、快速的响应、舒适的交互；30 年、500 条事件也要滑得动
3. **温馨简约的美学** - 页面简洁，UI元素舒适温暖，有人味

### **一条贯穿全局的设计约束：信息密度分层**
人生记录会越记越多。任何界面设计都必须回答「记满 500 条之后还好用吗」：
- 默认视图只呈现 **重要程度 ≥ 4 的大事**，小事收在「展开该年」之后
- 视觉权重严格随重要程度递减：里程碑（5）＞大事（4）＞普通（3）＞小事（1-2）
- 密度切换（按年 / 按月 / 全部）是一等公民控件，不是藏在设置里的开关

## ✨ 核心交互体验

### **时间线交互**（最核心）

#### **纵向时间线（核心视图）**
布局自上而下为「现在 → 出生」，即最新事件在顶部，出生节点在最底部（用户最关心近期，同时向下滚动 = 回溯过去，符合"往下挖历史"的心理模型）。

- 📌 出生节点固定为时间轴终点，带 👶 图标和「人生的起点」标签
- 🛣 **阶段泳道**：时间区间事件（幼儿园/小学/大学/某份工作）渲染为紧贴时间轴的**竖向色带**，宽 6px，用分类色 + 25% 透明度，带圆角端点；未结束的区间（`isOngoing`）顶端做渐隐处理表示"延续至今"
- 📍 时间点事件为轴上的圆形节点，卡片在两侧之字形排列
- 🔠 **视觉权重分层**：
  - 里程碑（5）：节点 16px + 外发光环 + 卡片带分类色左边框 4px
  - 大事（4）：节点 12px + 标准卡片
  - 普通（3）：节点 10px + 卡片无阴影
  - 小事（1-2）：默认折叠为**紧凑单行条目**（一行文字 + 日期），不占用完整卡片
- 📅 **吸顶年份**：滚动时当前年份标签吸附在视口顶部，同时显示「当时 X 岁」
- 🗓 **年份导航尺**：桌面端右侧常驻竖向标尺，列出所有有事件的年份 + 对应年龄，事件数量用小圆点密度表示；点击平滑滚动定位，当前年份高亮
- 🔍 **密度切换**：顶部提供「只看大事 / 按年 / 全部」三档，切换时卡片做淡入淡出而非重排跳动
- 💫 悬停事件卡片时，卡片轻微放大和阴影增强，时间轴节点高亮放大
- ⚡ 点击卡片展开详情，有平滑的高度动画
- 🎯 从搜索结果跳转时，目标卡片平滑滚动到视口中央并**高亮呼吸 1.5 秒**
- ♿ `prefers-reduced-motion` 时所有位移/缩放动画降级为瞬时切换

#### **模糊日期的展示规则**
用户记不清具体日期是常态，展示必须如实，不能伪造精度：

| 精度 | 展示格式 | 示例 |
|------|----------|------|
| `day` | YYYY年M月D日 | 2015年6月15日 |
| `month` | YYYY年M月 | 2015年6月 |
| `year` | YYYY年 | 2015年 |

- 精度低于 `day` 时，日期文字后不加任何推测性内容
- 区间事件：`2010年 – 2016年`；未结束：`2021年3月 – 至今`
- 年龄展示同步降级：`day` → 「12 岁 3 个月」，`year` → 「约 12 岁」

#### **时间点 vs 时间区间的视觉区分（核心规范）**
两类事件在时间轴上必须用**完全不同的视觉语言**，不靠文字说明也能一眼分辨：

| 维度 | 时间点 `point` | 时间区间 `period` |
|------|----------------|-------------------|
| 轴上形态 | **实心圆节点**（分类色填充 + 白/深色描边环） | **竖向色带**：从起始位置延伸到结束位置，宽 6px，分类色 25% 透明度，两端圆角；起止两端各一个**空心小横杠**标记 |
| 卡片标识 | 左上角 `●` 圆点图标 | 左上角 `▮` 条形图标 |
| 卡片边框 | 分类色左边框 | 分类色左边框 + 卡片底部一条与色带同色的连接引线，指向色带 |
| 日期文案 | `2019年6月8日` | `2016年9月 – 2019年6月`，右侧接灰色徽章 `3 年` |
| 未结束区间 | — | `2021年3月 – 至今`，色带顶端 40px 渐隐 + 末端呼吸光点 |
| 悬停 | 节点放大到 16px | 整条色带不透明度提到 55%，起止两端标记放大，同时高亮同一区间内的点事件 |

补充规则：
- **短区间保底**：跨度只有几天的区间（如 8 天的旅行），色带最小渲染长度 24px，并在卡片上显示 `8 天`，不允许短到看不见
- **多区间并行**：同期存在多个区间（在读书 + 兼职）时，色带向右并排排列，间距 4px，最多并排 3 条，超出折叠为 `+N`
- **跨年不切碎**：区间跨越多个年份分组时，色带连续贯穿这些年份标签，卡片只在起始年份出现一次
- **移动端**：色带贴左侧轴线，宽度降为 4px，`3 年` 徽章保留

#### **表单中的区分（添加/编辑）**
- 表单第一个控件就是分段切换器：`● 时间点 | ▮ 时间区间`，选中态用品牌色填充
- 选「时间点」：显示单个日期字段 + 精度切换（年/月/日）
- 选「时间区间」：日期区域动画展开为「起始日期 → 结束日期」两行，各带独立精度切换，下方一个「至今（尚未结束）」复选框，勾选后结束日期字段禁用并显示"至今"
- 切换类型时已填的起始日期保留，不清空
- 结束日期早于起始日期时即时报错（不等提交）
- 区间字段下方实时预览计算出的跨度：`共 3 年 9 个月`

#### **关键动画**
```
卡片进入: 淡入 + 轻微向上滑动 (300ms, ease-out)
悬停: 缩放 1.02 + 阴影增强 (200ms, ease-out)
展开详情: 高度平滑展开 (400ms, ease-out)
滚动时间线: 平滑滚动 (无生硬跳跃)
页面切换: 淡入淡出过渡 (200ms)
```

### **事件管理交互**

#### **添加事件**
- 🔘 浮动按钮（右下角），用"+号"图标；全站可用
- 📝 点击打开模态框，表单默认聚焦在事件标题输入框
- ✍️ 表单字段从上到下：标题 → 类型（时间点/区间）→ 日期 **+ 精度切换（年/月/日）** → 重要程度 → 分类 → 描述
- 🎚 重要程度用 5 段滑块或星级，默认 3；标签文案为「小事 / 值得记 / 重要 / 大事 / 里程碑」
- 🔁 提供「保存并继续添加」，保存后表单清空但不关闭，方便一次性补录多年往事
- 💾 保存时有微妙的"保存成功"反馈（短暂的绿色勾选动画）

#### **人生模板（冷启动关键）**
- 首次建档后，在空时间线上直接提示「根据出生日期生成上学阶段？」
- 按常见学制推算幼儿园、小学、初中、高中、大学的起止年份，生成为**草稿态**区间事件（视觉上虚线边框）
- 用户可逐条确认、修改年份或删除；一键「全部确认」转为正式事件
- 模板生成的日期精度默认为 `year`，如实表达"这是推算值"

#### **编辑事件**
- ✏️ 事件卡片上点击"编辑"图标进入编辑模式
- 🔄 数据预填充，用户可修改任何字段
- 📋 **列表视图**：时间轴之外提供紧凑列表/表格视图（日期 / 标题 / 分类 / 重要程度），支持行内快速编辑，用于连续整理多条事件
- 🗑️ 底部有"删除"按钮，点击时需确认

#### **删除事件**
- ⚠️ 删除前显示确认对话框："确定要删除这个事件吗？"
- 🔙 删除后底部弹出 Toast「已删除《事件名》 · 撤销」，30 秒内可恢复（软删除，超时清理）

### **搜索与筛选**
- 🔍 搜索框位于页面顶部，支持实时搜索（标题 + 描述）；`/` 快捷键聚焦
- 🏷️ 分类筛选：以小芯片形式展示，可多选
- ⭐ 重要程度筛选：「只看大事」快捷开关 + 精细档位
- ⏰ 年份筛选与快速跳转：右侧年份标尺点击跳转，或选择年份区间
- 🧮 筛选条件可叠加，实时显示「命中 N / 共 M 条」，一键清除全部条件

## 🎭 页面设计规范

### **整体布局**

#### **标准页面结构**
```
┌─────────────────────────────────────┐
│ Header (固定)                        │
│ Logo | 标题 | 用户菜单 | 主题切换   │
├─────────────────────────────────────┤
│                                     │
│  Sidebar (可选)   │  Main Content   │
│  导航/分类菜单    │  时间线或内容   │
│  用户信息         │                 │
│                  │                 │
│                  │  [+ 按钮]       │
└─────────────────────────────────────┘
```

### **Header 设计**
- 高度: 64px（包含内边距）
- 背景: 纯白或浅暖色 (#F8F7F5)
- 分隔线: 1px 浅灰 (#E5E5E5)
- 左侧: Life-Point Logo + 项目名称
- 中央: （保留给未来功能）
- 右侧: 搜索（可选）| 主题切换 | 用户菜单（档案/设置/关于）

### **时间线页面**
- 中心对齐，时间轴为竖直线
- 时间轴线宽: 2px，颜色: #D4A574
- 阶段泳道: 宽 6px，紧贴时间轴，分类色 25% 透明度，两端 3px 圆角
- 节点圆圈: 基准 12px 直径，填充为分类色，悬停放大到 16px；里程碑事件 16px + 外发光
- 事件卡片: 最大宽度 400px（确保清晰阅读）
- 左右对称或交替排列，取决于屏幕宽度
- 右侧年份标尺: 宽 56px，桌面端常驻，平板/移动端折叠为顶部横向年份条
- 移动设备: 所有卡片排在时间轴一侧，防止左右切换

### **事件卡片设计**
```
┌─────────────────────────┐
│ ▍🏆 事件标题        ★★★★★│ ← 左边框=分类色，右侧=重要程度
├─────────────────────────┤
│ 2024年6月15日 · 28岁3个月 │ ← 时间 + 当时年龄（按精度降级）
│ 🏆 成就                  │ ← 分类标签
├─────────────────────────┤
│ 这是事件的描述内容       │ ← 描述区（2 行后省略号截断）
├─────────────────────────┤
│ 📍 地点   [编辑] [删除]  │ ← 元信息 + 操作按钮
└─────────────────────────┘

小事（重要程度 1-2）的紧凑形态：
· 2024年6月15日  去新疆旅游 ✈️        [⋯]

悬停时:
- 卡片阴影增强
- 背景轻微变浅
- 操作按钮更明显（默认半透明，悬停实心）
```

### **个人档案页面**
- 简洁布局，突出用户信息
- 头像（圆形，120px）+ 用户名 + 出生日期（计算年龄）
- 简介区域（可编辑）
- 统计卡片（Phase 2+）：总事件数、最早事件、最新事件等
- 快速操作按钮：编辑档案、导出数据、设置

### **底部（Footer）**
- 简约设计，仅包含必要信息
- 版本号、开源链接、反馈链接
- 可选: 一句鼓励的文案，如"记录生活，反思人生 ✨"

## 🎬 动画与过渡

### **动画时长指南**
- 快速反馈: 200ms (按钮悬停、输入框焦点)
- 标准动画: 300ms (卡片进入、淡入淡出)
- 较长动画: 400-500ms (模态框进入、复杂展开)
- 过度动画: > 600ms (避免，容易显得卡顿)

### **关键动画清单**
| 操作 | 动画类型 | 时长 | 缓动函数 |
|------|--------|------|--------|
| 页面加载 | 淡入 | 300ms | ease-out |
| 卡片进入 | 淡入 + 上滑 | 300ms | ease-out |
| 卡片悬停 | 缩放 + 阴影 | 200ms | ease-out |
| 打开模态框 | 淡入 + 向下滑入 | 300ms | ease-out |
| 关闭模态框 | 淡出 + 向下滑出 | 200ms | ease-in |
| 保存成功 | 勾选动画 | 600ms | ease-out |
| 滚动到事件 | 平滑滚动 | 500ms | ease-in-out |
| 分类切换 | 内容淡入淡出 | 200ms | ease-in-out |

## 📱 响应式设计

### **断点设置**
```
Mobile:     < 640px   (竖屏手机)
Tablet:     640-1024px (平板)
Desktop:    > 1024px   (桌面)
```

### **各设备的时间线展示**
| 设备 | 时间线宽度 | 卡片排列 | 字体大小 |
|------|----------|--------|--------|
| Mobile | 100% | 单侧排列（左或右） | 14-16px |
| Tablet | 80% | 两侧交替 | 15-17px |
| Desktop | 70% 居中 | 左右对称 | 16-18px |

### **移动端优化**
- 浮动 + 按钮放在易触及位置（下方）
- 事件卡片宽度自适应，最小 280px
- 模态框全屏或大部分屏幕宽度
- 字体大小不小于 16px（避免自动缩放）

## ♿ 可访问性规范

### **键盘导航**
- Tab 键可聚焦所有交互元素
- Enter 键激活按钮/链接
- Escape 键关闭模态框/菜单
- 上下箭头在时间线中导航事件
- Ctrl/Cmd + F 打开搜索

### **屏幕阅读器**
- 所有图标都有 aria-label
- 表单字段有关联的 label
- 重要信息有语义化标记
- 时间轴用 <ol> 标签表示有序列表

### **色彩对比度**
- 所有文字与背景对比度 ≥ 4.5:1
- 交互元素对比度 ≥ 3:1
- 避免只用颜色传达信息（配合文字或图标）

## 🎯 用户体验检查清单

### **加载体验**
- [ ] 页面首屏加载时间 < 2秒
- [ ] 500+ 事件时时间线滚动稳定 60fps（超过阈值启用虚拟滚动 + 关闭进入动画）
- [ ] 年份标尺跳转在 100ms 内开始响应
- [ ] 加载过程有进度反馈（骨架屏优于 spinner）

### **输入体验**
- [ ] 表单字段有清晰的焦点样式
- [ ] 输入错误有即时反馈（不是提交时才提示）
- [ ] 成功保存有视觉反馈（不仅仅是消息提示）
- [ ] 支持回车键快速保存

### **导航体验**
- [ ] 当前位置清晰（面包屑或高亮导航）
- [ ] 返回上级操作便利（浏览器返回键 + UI 返回按钮）
- [ ] 页面切换过渡平滑，不出现闪烁

### **移动端体验**
- [ ] 所有按钮大小 ≥ 48×48px（易点击）
- [ ] 模态框宽度适配，不全屏占用（留出边距）
- [ ] 虚拟键盘出现时表单不被遮挡

### **深色模式体验**
- [ ] 所有元素在深色模式下都清晰可见
- [ ] 图片/头像在深色模式下不过曝
- [ ] 不强制使用深色模式，尊重用户选择

## 💡 设计灵感参考

虽然 Life-Point 有自己独特的风格，但以下产品的设计思想可以参考：

- **Apple Reminders**: 简洁、清晰的 UI，流畅的交互
- **Day One**: 温暖的配色，个人日记的整体感觉
- **Timeline.app**: 可视化时间线的呈现方式
- **Motion**: 优秀的动画细节和过渡
- **Notion**: 模块化的灵活布局

**关键学习点**:
- 少即是多：删除所有非必要 UI 元素
- 微交互：细微的动画让操作感觉更贴心
- 信息层级：重要信息优先展示，次要信息隐藏在折叠下
- 一致性：确保所有页面的交互方式统一

## 🎨 设计工作流（开发时参考）

### **前期设计产出物**（可选，非必须）
1. **线框图** (Wireframe): 确定布局和信息层级
2. **设计稿** (Design System): Figma 或 Adobe XD
3. **组件库** (Component Library): 按功能分类定义可复用组件
4. **交互原型** (Prototype): 演示关键动画和流程

### **编码时遵循的原则**
- 创建 `tailwind.config.js` 并将本文所有颜色/间距定义为 tokens
- 创建 `.vue` 组件对应每个设计组件
- 在 `styles/` 下定义全局 CSS 变量和动画
- 使用 CSS 类管理深色模式（`.dark` 前缀）
- 所有动画使用 `@apply` 或 Tailwind 的 `transition` 工具类

## 📋 总结：设计的三个层次

### 第一层：**清晰（Clarity）**
- 时间轴是焦点，一目了然
- 信息层级明确，重要信息突出
- 界面元素有清晰的用途和交互反馈

### 第二层：**温馨（Warmth）**
- 色彩温暖柔和，不刺眼
- 动画流畅自然，不生硬
- 文案亲切友好，有人性化

### 第三层：**丝滑（Smoothness）**
- 每个交互都有平滑的过渡
- 响应速度快，无延迟感
- 加载、保存、删除等操作都有反馈
