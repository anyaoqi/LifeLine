> 最近更新：2026-07-04

## 1. 项目概述与目标

**项目名称**: Life-Point  
**项目描述**: 一个用于记录和可视化个人人生重要事件的应用。用户可以创建个人档案，记录从出生到现在的关键事件，并通过可视化时间线查看人生轨迹。  
**目标用户**: 希望记录和反思人生重要时刻的个人用户  
**核心价值**: 帮助用户以时间线的形式可视化和记录人生中的重要事件，提供一个个性化的人生档案库。

## 3. 技术栈推荐与理由

### **前端框架: Vue 3 + TypeScript**
- ✅ 学习曲线平缓，易于吸引开源贡献者
- ✅ 官方生态完善（Router、Pinia、VueUse等）
- ✅ TypeScript支持优秀，开发体验好
- ✅ 相比React更轻量级，适合个人项目

### **状态管理: Pinia**
- ✅ Vue官方推荐，是Vuex的现代化替代
- ✅ API简洁直观，易于学习和维护
- ✅ 完美的TypeScript支持
- ✅ 包体积小（~2.5KB）

### **数据存储方案**

**MVP+Phase 2 阶段**:
- **IndexedDB** (dexie.js): 存储事件数据（支持大容量、复杂查询）
- **localStorage**: 存储用户设置、主题、缓存
- **特点**: 完全本地化，无后端依赖，支持离线使用

**Phase 3+ 阶段**:
- **后端API**: 用户认证和数据同步
- **PostgreSQL**: 关系型数据库，支持事务和复杂查询
- **Redis**: 缓存和会话管理（可选）

### **UI框架: Tailwind CSS**
- ✅ 原子化CSS，高度定制化，学习成本低
- ✅ 支持暗黑模式开箱即用（`darkMode: 'class'`）
- ✅ 生产环境CSS体积小（tree-shaking）
- ⚠️ 实际采用 **Tailwind v3.4**（原模板曾误配 v4，已降级以匹配现有配置写法）
- 📝 MVP 未引入 Headless UI —— 模态框、按钮等组件均自行用 Tailwind 实现

### **可视化方案**
- **MVP**: ❌ 未使用任何图表库 —— 时间线采用**纯 CSS 自定义实现**（中心竖线 + 节点 + 卡片），更贴合设计文档的温馨简约美学
- **Phase 3+ 统计面板**: 届时再评估引入 Chart.js（轻量）或 D3.js（灵活自定义）

### **其他核心工具**

| 工具 | 选择 | 状态 | 理由 |
|------|------|------|------|
| 构建工具 | Vite | ✅ v0.1.0 | 快速热更新，开发体验优秀 |
| 包管理 | npm | ✅ v0.1.0 | 环境已就绪（原规划 pnpm，可后续切换） |
| 路由 | Vue Router 4 | ✅ v0.1.0 | 官方推荐，功能完善 |
| 状态管理 | Pinia | ✅ v0.1.0 | Vue 官方推荐，API 简洁 |
| 数据库 | Dexie (IndexedDB) | ✅ v0.1.0 | 本地大容量存储，支持复杂查询 |
| 测试框架 | Vitest + Vue Test Utils | ⏳ Phase 3 | 轻量级，与Vite无缝集成 |
| 代码规范 | ESLint + Prettier | ⏳ Phase 3 | 业界标准 |
| Git Hooks | Husky + lint-staged | ⏳ Phase 3 | 自动化质量检查 |
| 文档 | VitePress | ⏳ 未来 | Vue官方文档工具 |

## 5. 核心数据模型（v0.2.0）

### **用户档案**
```typescript
interface UserProfile {
  id: string;
  name: string;                    // 用户名（必填）
  birthDate: string;               // 出生日期 ISO 格式（必填）
  bio?: string;                    // 个人简介
  avatar?: string;                 // 头像图片 URL
  createdAt: string;
  updatedAt: string;
}
```

### **生活事件（v0.2.0 — 支持时间点 + 时间区间）**
```typescript
type EventType = 'point' | 'period';
type EventCategory =
  | 'education' | 'work' | 'life' | 'travel'
  | 'love' | 'health' | 'achievement' | 'other';

interface LifeEvent {
  id: string;
  userId: string;
  title: string;                   // 事件标题（必填）
  type: EventType;                 // 事件类型：时间点 / 时间区间
  date: string;                    // 起始日期 ISO 格式（必填）
  endDate?: string;                // 结束日期（仅 type='period' 时有效）
  description?: string;            // 事件描述
  category: EventCategory;         // 事件分类
  createdAt: string;
  updatedAt: string;
}
```

## 8. 关键技术决策说明

### **为什么选择Vue 3而不是React?**
- Vue学习曲线更平缓，对新手更友好
- 官方生态完善一致，不存在选择困难
- 本项目规模适中，不需要React的灵活性
- 有利于吸引更多开源贡献者

### **为什么使用IndexedDB而不是localStorage?**
- localStorage限制~5-10MB，IndexedDB支持更大容量
- 支持复杂数据结构、索引和事务
- dexie.js提供简洁易用的API
- 性能更优，适合数据查询和更新

### **为什么选Tailwind而不是其他CSS框架?**
- 原子化设计，高度定制化
- 生产CSS体积小（通过tree-shaking）
- 学习成本低，易于上手
- 完美支持暗黑模式

### **为什么暂不使用后端?**
- MVP阶段快速验证核心价值
- 降低项目复杂度和维护成本
- 用户数据完全本地化，隐私更好
- 后期按需添加后端功能

## 10. 常见问题

**Q: MVP需要多长时间?**  
A: 对于有经验的开发者约7-14天，初级开发者可能需要3-4周。建议预留充足时间进行测试和文档编写。

**Q: 何时开源?**  
A: Phase 2 已完成，功能相对完整，代码质量稳定。建议在 Phase 3 完成（分享、统计等功能）后正式开源，届时会有更完整的功能集和文档。

**Q: 如何吸引贡献者?**  
A: 提供清晰的贡献指南、标记"good first issue"、及时回复PR/Issue、建立友好的社区氛围。

**Q: 后期如何引入用户认证?**  
A: Phase 3时在后端实现OAuth2或JWT认证，迁移本地数据到云端。通过迁移脚本帮助现有用户升级。
